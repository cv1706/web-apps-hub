公式說明與注意事項

估算最大吊重

最大吊重 = (噸數 x 3 / 半徑) x 折減係數

例：25 噸吊車，半徑 8 公尺
(25 x 3 / 8) x 75% = 7.03 噸

估算作業半徑

作業半徑 = 噸數 x 3 / 吊重

例：16 噸吊車，吊重 10 噸
16 x 3 / 10 = 4.8 公尺

注意事項

  • 適用於 50 噸以下小型吊車（含汽車吊）
  • 前提為支腿跨距約 6.2 公尺
  • 折減係數預設 75%，已概算大臂與吊鉤重量
  • 實際操作需參考吊車性能表，並考量大臂長度、配重箱配置
  • 大臂節數與長度並非越多越好，需依實際工況選擇

本工具僅供估算參考，不得作為正式工程計算依據。實際作業請以吊車原廠性能表為準。
