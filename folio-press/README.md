# Folio Press 繁體中文排版工作台

本目錄為「印務室 Folio Press」獨立純前端 Web 應用之實體部署目錄。

## 快速開啟方式

直接使用現代瀏覽器開啟本目錄下的 `index.html`：
- 本機路徑：`Tools/web_apps/03-日常工具/folio-press/index.html`

## 核心特性

1. **100% 離線純前端架構**：不依賴任何外部後端或授權伺服器，資料絕不離境上傳。
2. **出版級 6 大核心主題**：瑞士顧問、聖水象牙、東京雜誌、金融簡報、牛津學術、對話原貌。
3. **一鍵去 AI 感淨化**：自動過濾對話寒暄客套贅詞與結尾標籤。
4. **雙階物理分頁演算**：防孤行孤頁（Keep-with-next）與動態頁碼目錄反填。
5. **四合一交付物匯出**：A4 向量 PDF、3 倍解析度長圖、乾淨 Markdown、Word 富文本。
