# 投資情報小助手 · 全球總經、科技情報與地緣局勢戰情室操作指南

## 一、 系統概述

**投資情報小助手（Global Macro Intel Dashboard）**是一套整合「台股與美股量化行情」、「全球九大主要股市矩陣」、「美股 AI 巨頭深度看板」、「高精度世界向量地圖與地緣政治雷達」、「個人模擬交易部位連動」以及「AI 宏觀戰報問答夥伴」的四合一即時戰情室系統。

本系統採用純前端單頁應用（SPA）架構與後端單一真實來源（SSOT）原子化快照機制，具備零外部圖磚相依、離線立即可用、毫秒級載入等高可靠性特性。

---

## 二、 目錄架構

```
Tools/web_apps/01-投資量化/global_intel_dashboard/
├── sync_intel_data.py       # 後端數據同步引擎 (整合行情 API、投組損益與地緣情報)
├── launch_dashboard.py      # 本地伺服器啟動器 (具備 REST API 與瀏覽器自動喚醒)
├── index.html               # 戰情室完整前端 SPA 介面 (純 CSS/SVG/JS，零外部 CDN 相依)
├── world_vector.js          # 高解析度真實世界地理邊界向量路徑庫 (14.6 萬字元)
├── intel_snapshot.js        # 純前端 file:// 載入專用 JS 快照 (徹底免除 CORS 限制)
├── intel_snapshot.json      # 戰情室單一真實來源 (SSOT) JSON 快照
└── README.md                # 本使用手冊
```

## 三、 快速啟動操作 SOP

### 1. 方式 A：啟動本地伺服器（推薦，支援 API 動態刷新）
在專案根目錄或終端機中執行：
```powershell
python "Tools/web_apps/01-投資量化/global_intel_dashboard/launch_dashboard.py"
```
* **運作機制**：自動尋找可用通訊埠（預設 8765），啟動多執行緒 HTTP 伺服器，並於 0.8 秒後自動呼叫本機預設瀏覽器開啟網頁。
* **網址**：`http://127.0.0.1:8765/index.html`
* **API 支援**：點擊網頁上的「重新抓取」按鈕可直連 `/api/refresh` 觸發後端秒級重新同步。

### 2. 方式 B：離線單純開啟靜態頁面
若不想啟動 Python 服務，可直接以瀏覽器雙擊開啟：
`Tools/web_apps/01-投資量化/global_intel_dashboard/index.html`
* **運作機制**：直接讀取 `intel_snapshot.js` 與 `world_vector.js`，不受瀏覽器跨域（CORS）限制，即使斷網亦可 100% 正常渲染圖表與向量地圖。

### 3. 手動重跑後端數據同步
```powershell
python "Tools/web_apps/01-投資量化/global_intel_dashboard/sync_intel_data.py"
```

## 四、 六大模組功能與操作說明

### 1. 頂部導航與重大警報橫幅
* **視角切換 Tab**：
  * **今日早報（預設）**：六大核心模組全景監控。
  * **今天的世界**：切換為沉浸式大地圖展開視角，集中觀察全球地緣政治焦點。
  * **我的投資 -9.3%**：點擊切換進入個人模擬投資組合戰情面板，顯示帳戶總資產（$907,000）、總損益率、加權指數回撤 -20.3% 之停損定錨應對策略、持倉清單與交易日誌。
* **五張重大警報彩色卡片**：
  * 美評估重啟空襲伊朗（金黃色預警）
  * 波灣油輪遭飛彈擊擊（深紅色危險）
  * 剛果伊波拉指數成長（紫色公衛警報）
  * 美選後 AI 股全球崩跌（深青藍市場異動）
  * 台股加權達到你的條件（亮紅風控停損警報）
  * *互動*：點擊任一警報卡，世界地圖與局勢清單將自動聚焦高亮對應事件。

### 2. 左上看板：台股加權指數深度監控
* **即時點位與報酬矩陣**：展示大盤 39,702 點、當日漲跌幅，以及「比昨天、近五天、近一個月、比一年前」四合一報酬矩陣。
* **歷史走勢折線圖**：採用原生向量 SVG 動態渲染一年日 K 收盤價波形曲線。
* **一年高低點位階量規（Gauge Bar）**：標示一年最低 26,433、一年最高 49,823，並以漸層滑軌標記游標位於 57% 中間位置，距年高點 -20.3%。

### 3. 中上看板：全球主要股市矩陣
* **涵蓋市場**：S&P 500、那斯達克、日經 225、韓國 KOSPI、香港恆生、上證、德國 DAX、英國富時、印度 Nifty 共 9 大指數。
* **Sub-tabs 四大維度即時切換**：
  * **今天漲跌**：卡片大字顯示今日變動率與迷你 Sparkline。
  * **近五天**：卡片大字切換為近 5 日累積報酬率。
  * **一年走勢**：卡片大字顯示過去一年走勢幅度。
  * **一年內位置**：卡片顯示 52 週位階百分比（如「中間 57%」、「偏低 28%」）。

### 4. 右上看板：全球局勢高精度 SVG 世界地圖
* **真實海岸線圖資**：內建業界標準高解析度地理向量邊界（14.6 萬字元），完整呈現歐亞非、美洲、大洋洲、日本、台灣等真實地貌。
* **引線與膠囊標籤（Leader Lines & Callout Badges）**：
  * 核心發光點搭配 CSS 動態脈衝光環。
  * 微彎折線引出彩色事件膠囊（波灣油輪遭飛彈擊擊、美評估再襲伊朗、剛果伊波拉、選後 AI 監管等）。
  * 點擊標籤或下方局勢列表，雙向連動高亮。
* **地圖工具列**：支援按鈕「+ 放大」、「- 縮小」與「重置視角」。

### 5. 左下看板：美國 AI 股看板
* **費半 vs AI 九強雙曲線**：將費城半導體（SOX）與 9 檔 AI 巨頭收盤價以基期 100（Base=100）進行歸一化對比，繪製一年期雙軌折線圖。
* **9 大龍頭熱力卡片**：NVDA、台積電 ADR、微軟、Google、Meta、亞馬遜、蘋果、博通、AMD，各卡片直接顯示現價、今日漲跌與近 5 日累積漲跌幅。

### 6. 中下與右下：AI 世界動態與財經焦點
* **AI 世界動態**：分類彙整「新模型（GPT-6 Cyber、Gemini Omni 等）」、「資金與 IPO（Fal、Thinking Machines 等）」與「重大日程（NVIDIA 財報日等）」。
* **財經焦點**：以彩色標籤分類整理「升息（Fed 機率）」、「就業（非農數據）」、「油價（跳水分析）」、「護盤（國安基金動態）」與「法說（台積電海外說明會）」。

### 7. 問 AI 夥伴（AI Chat Drawer）
* 點擊右上「問 AI 夥伴」展開側欄抽屜。
* 提供 4 組熱門問題快捷標籤：
  * 台股回撤 20% 應對策略？
  * 波灣局勢對油價影響？
  * 美股 AI 九強技術位階？
  * 國安基金護盤效應？
* 點擊標籤或手動輸入，皆可立即獲得具備量化停損與產業脈絡的專業回答。

### 8. 輔助操作功能
* **重新抓取**：優先呼叫後端 API，純前端模式下自動更新時間標籤並彈出 Toast 提示。
* **資料來源**：彈出視窗詳列各市場技術鏈路與延遲狀態。
* **設定**：彈出偏好視窗，支援切換色彩習慣（國際綠漲紅跌／台股紅漲綠跌）與大盤回撤警報門檻。
* **複製**：將當前 AI 一句話、台股大盤、美股與地緣焦點自動排版為標準文字戰報並寫入剪貼簿。
* **閱讀 摘要**：點擊展開完整的 AI 全景宏觀長篇總研報視窗。
