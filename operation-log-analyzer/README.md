# 工業運轉參數智能檢驗工具 (Industrial Operation Log Inspector)

專為工業運轉紀錄（SCADA / DCS / 記錄器 CSV 匯出檔）設計的純前端、免伺服器、全離線時間序列參數分析與異常檢驗小工具。

---

## 核心特性

1. **多機型動態自適應（Zero Hardcoding）**：
   - 自動嗅探分號（`;`）與逗號（`,`）分隔符號。
   - 自動正則拆解欄位：自動識別機型（如 `TW_YEASHIN_T5`）、位號（如 `AIT119`、`PT118_VAL`）與工程單位（如 `Deg_C`、`ppm`、`Nm3/h`、`mbar`、`bar`、`%`、`min`）。
   - 欄位數量增減或更換機型無需修改程式碼，即拖即用。

2. **物理量智能分組與多圖時間同步**：
   - 依物理量將數十項參數自動劃分為「溫度」、「高壓」、「微壓與差壓」、「流量與純度」、「控制與閥位開度」、「計時週期」等獨立看板。
   - 所有圖表共享時間軸，滑鼠游標、縮放（DataZoom）自動同步聯動。

3. **偏差閾值監控與異常事件清單**：
   - 支援為每個位號設定高高限（HH）、高限（H）、低限（L）、低低限（LL）與每分鐘最大變化率（RoC）。
   - 提供「3-Sigma 智能生成」功能，可自動依目前實測數據分佈估算上下限。
   - 點擊右側異常事件，圖表立即縮放聚焦至該時間點前後 30 分鐘，並標記異常數值。

4. **100% 離線運行與資安合規**：
   - 已內建離線版 `echarts.min.js` 與 `papaparse.min.js`。
   - 數據完全保留在瀏覽器本地記憶體，不經過任何外網伺服器。

---

## 使用方式

1. 雙擊執行目錄下的 `啟動工具.bat`（或直接以 Chrome / Edge 開啟 `index.html`）。
2. 將您下載的 CSV 運轉紀錄檔案拖放至網頁中央（亦可選取目錄下的 `sample_data.csv` 進行測試）。
3. 系統自動完成圖表繪製，並於右側列出偏差警示。
4. 點擊「設定參數警示閾值」可調整門檻，設定將自動保存在瀏覽器，下次載入同機型時自動套用。
5. 檢核完畢後，點擊「匯出異常清單 (CSV)」或「列印檢驗報告」產出紀錄。
