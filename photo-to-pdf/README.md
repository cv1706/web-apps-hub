本目錄為「光印轉換所 Photo to PDF」獨立純前端 Web 應用之實體部署目錄。

## 快速開啟方式

直接使用現代瀏覽器開啟本目錄下的 `index.html`：
- 本機路徑：`Tools/web_apps/03-日常工具/photo-to-pdf/index.html`
- Web Apps Hub 部署路徑：`output/web-apps-hub/photo-to-pdf/index.html`

## 核心特性

1. **100% 離線純前端運算**：全程本機記憶體組裝，個資證件、單據發票絕不上傳雲端伺服器。
2. **iPhone HEIC 原生解碼**：拖曳 iOS 原生相片自動轉換為 JPEG，並具備 EXIF 自動轉向校正。
3. **雙軌即時預覽**：支援畫布「分頁模擬」所見即所得，以及「全螢幕 PDF 閱讀器」匯出前完整審查。
4. **靈活排版與多圖拼貼**：支援自適應無白邊、標準 A4/A3/Letter、單頁 1/2/4 張網格拼貼。
5. **四階壓縮與防偽浮水印**：輕巧/平衡/高清/無損品質控制，支援中文斜向防偽浮水印與置中頁碼。
