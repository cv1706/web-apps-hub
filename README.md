# Web Apps Hub · 雲端數位工具與互動應用

本專案為純前端靜態 Web 工具箱與遊戲整合入口，完全開源且不包含任何私有數據或金鑰。

## 🎯 收錄專案一覽

1. **三國戰棋 · 歷史全紀元 (`/games/three-kingdoms-chess/`)**
   - 50 關史詩戰役沙盤與 100 位專屬持武立繪武將名冊。
   - 包含將魂突破升星、太史慈「貫日連珠」直線雙穿透與軍團增益防護體系。

2. **台灣即時路況動態看板 (`/taiwan-traffic-live/`)**
   - 全台國道與快速道路車速流向與壅塞分級監測。

3. **國道高速公路計程通行費試算 (`/highway-toll-calculator/`)**
   - 全台國道交流道計程收費與車種費率精準試算。

4. **移動式起重機吊裝配重安全試算 (`/crane-calculator/`)**
   - 工業安全與高壓氣體作業標準之主臂長度、作業半徑與額定總負荷校核。

## 🚀 部署方式 (GitHub Pages)

1. 在 GitHub 建立公開儲存庫 `web-apps-hub`。
2. 進入 **Settings > Pages > Build and deployment > Source**，切換為 **GitHub Actions**。
3. 推送程式碼至 `main` 分支即可自動完成上線發布。
